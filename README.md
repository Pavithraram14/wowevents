# Wow Events and Promotions — Website

A responsive five-page static website with a pink and rainbow celebration theme.

## Pages
1. `index.html` — Home / hero and highlights
2. `about.html` — Company introduction and values
3. `services.html` — Event management services
4. `gallery.html` — Event inspiration gallery
5. `careers.html` — Vacancies and contact information

## Run locally
Open `index.html` in a browser. No build tools or installation are required.

## Customise before publishing
- Replace the sample gallery images with photographs of your actual event arrangements.
- Confirm the postal code: the address was entered as `63680-11`, exactly as supplied.
- The email was interpreted as `wowevents@gmail.com` from “Wow Events at Gmail.com”. Confirm this address before publishing.
- Update vacancy status and role descriptions as needed.
- Images and Google Fonts load from external services, so an internet connection is needed for those assets.

## Publish
Upload the contents of this folder to any static web host (for example, GitHub Pages, Netlify or your hosting provider).
